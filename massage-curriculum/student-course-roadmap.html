This is the recommended path through the website. Use the search page anytime you need to look up a specific answer.

How to use this course

For each topic: learn the theory → identify/palpate the anatomy → connect pathology and contraindications → practice the relevant hands-on technique → answer application questions → document/reassess. Do not wait until the end of the program to begin MBLEx review.
